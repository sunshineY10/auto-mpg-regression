# 实验说明 (README_experiments)

## 哪次运行适合上线生产
improved-v1-linear（Registry version 8）。理由：
1. 无泄漏评估：在与 baseline 完全相同的 79 条独立测试记录上评估；中位数与编码都在 Pipeline 内按训练折拟合，测试集全程不参与；
2. 指标持平略优：RMSE 3.2691 / R² 0.7906，优于 baseline（3.2727 / 0.7902）；
   但需如实说明 MAE 略差（2.4890 vs 2.4198）——增益微乎其微且不一致；
3. 数据质量更好：6 处 horsepower 缺失通过训练折中位数（95.0）被用上，origin 正确 one-hot 编码；
4. 形式最简单：线性回归 + 无正则化；CV 显示 Ridge 模型与 linear 相差不足 0.001（噪声级），按简约原则不引入额外超参；
5. 可复现：run 记录了 code_version（git SHA）与 data_version（DVC md5）双指纹。

## 优化的指标及为什么重要
主指标 RMSE（均方根误差，单位 mpg）。理由：本应用的输出是连续油耗值，
RMSE 与大误差同量级、对异常预测敏感，直接反映“预测偏离真实油耗多少英里/加仑”。
对油耗咨询类场景，大误差比典型误差更伤用户体验（报错 5 mpg 比报错 2 mpg 糟得多），
因此选 RMSE 而非 MAE 作主指标；R² 作为辅助参考（解释方差比例）。

诚实对照：在同一测试集上，清洗只让 RMSE 改善约 0.1%，MAE 略差，不能宣称“全面优于”；
CV 显示强正则化无收益，该数据规模下简单线性模型已经接近最优。
